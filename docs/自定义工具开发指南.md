# 自定义工具开发指南

> 面向使用「更多LLM工具」插件的用户。
> 学会写一个 Python 函数 → 保存 → AI 就能调用它。
>
> 本文档同时是一份**可直接喂给外部 AI 的规格说明** ——
> 见 [§6 给外部 AI 的提示词](#6-给外部-ai-的提示词复制即用)。

---

## 1. 这是什么

「自定义工具」让你用 Python 写一个函数，注册成 AI 可以调用的工具。

写完后，AI 会在需要时**自动搜索到并调用它** —— 就像调用插件自带的 110 个工具一样。

```
你写函数  →  保存到 WebUI  →  注册为 Wyc_custom_tool_xxx
                                      ↓
                        用户问 AI  →  AI 搜索工具  →  调用你的函数
```

**典型用途**：

- 调某个公开 API（天气、汇率、快递、IP 查询）
- 做一段特定计算（表达式求值、单位换算、日期推算）
- 处理文本（正则提取、格式转换、编码解码）
- 组合操作（读工作区文件 → 处理后返回）

**不适合**：需要密钥的私有服务（代码会明文存在配置里）、长时间运行的任务（有超时限制）、需要访问数据库的操作（沙箱禁止网络库的大部分用法）。

## 2. 快速开始（3 分钟）

在 WebUI 的「自定义工具」页点「新建工具」，填入：

**名称**：`当前时间`

**描述**：`获取当前日期和时间。当用户询问现在几点、今天几号时调用。`

**搜索词**：`时间, 几点, 现在, 日期, 今天`

**代码**：

```python
from datetime import datetime

def main() -> dict:
    """获取当前日期和时间。

    Args:
    """
    now = datetime.now()
    return {"status": "success", "message": now.strftime("%Y-%m-%d %H:%M:%S")}
```

保存后：
1. 点「试跑」验证能跑通
2. 在 QQ 里问 AI「现在几点了」→ AI 会搜到这个工具并调用

**这个例子的三个要点**：

| 要点 | 说明 |
|------|------|
| 必须有 `main` 函数 | 入口函数，默认就叫 `main`（可在保存时改，但建议保持 `main`） |
| 必须有 docstring | **必须有 `Args:` 段**，哪怕没有参数（写成空的 `Args:` 也行） |
| 必须返回 dict 或 str | 见 [§3.3](#33-返回值) |

## 3. 完整规范

### 3.1 入口函数

```python
def main(参数1: 类型, 参数2: 类型 = 默认值) -> dict:
    ...
```

| 规则 | 说明 |
|------|------|
| 函数名 | 默认 `main`。**必须是顶层函数**（不能定义在 class 里） |
| 参数 | 参数名即 AI 调用时要传的参数名。**参数越少越好**（AI 更容易传对） |
| 类型注解 | 可选但**强烈建议写**。不写就只能靠 docstring 判断类型 |
| 默认值 | 有默认值 → 该参数**可选**；无默认值 → **必填** |
| `*args` / `**kwargs` | 不支持，会被忽略 |
| `async def` | **支持**。需要 `await` 时用它（但沙箱里能用的异步库有限） |

### 3.2 docstring 格式（最容易出错的地方）

工具的参数表**从 docstring 的 `Args:` 段解析生成**。格式必须严格：

```python
def main(city: str, days: int = 1) -> dict:
    """查询指定城市的天气。

    Args:
        city(string): 城市名，如「北京」
        days(integer): 查询未来几天，默认 1
    """
```

格式要求（**逐条都不能错**）：

| 要求 | 正确 | 错误 |
|------|------|------|
| `Args:` 单独一行 | `    Args:` | `    args:`、`    参数:` |
| 参数行缩进 | 比 `Args:` 再缩进一级（通常 8 空格） | 与 `Args:` 同缩进 |
| 参数行格式 | `参数名(类型): 描述` | `参数名: 类型, 描述`、`参数名 (类型): 描述` |
| 冒号 | **英文冒号** `:` | 中文冒号 `：` |
| 括号 | **英文括号** `()` | 中文括号 `（）` |

**类型只能用这 6 个词**（写别的会被当成 `string`）：

```
string   integer   number   boolean   array   object
```

> ⚠️ **写错的后果**：参数表会缺失或类型错误，AI 传参会失败。
> **自检方法**：保存时页面下方的「参数预览」会实时显示解析结果 ——
> 如果参数没出现、或类型不对，就是 docstring 写错了。

**描述的重要性**：`描述` 会原样给 AI 看，是 AI 判断「该传什么值」的唯一依据。

```python
# ❌ 差：AI 不知道该传什么格式
city(string): 城市

# ✅ 好：明确格式与示例
city(string): 城市名，如「北京」或「Tokyo」
```

### 3.3 返回值

三种都支持：

```python
# ① dict（推荐，信息最全）
return {"status": "success", "message": "北京 晴，24℃"}

# ② dict + 错误状态
return {"status": "error", "message": "未找到该城市"}

# ③ 纯字符串（会被自动包装成 {"status":"success","message": <你的字符串>}）
return "北京 晴，24℃"
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | string | `success` 或 `error`。决定 AI 看到的是 ✅ 还是 ❌ |
| `message` | string | **给 AI 看的文本**。会原样进入 AI 的上下文 |
| `screenshot` | string | 可选。**图片文件路径**（如 `chart.png`），AI 会直接看到图片 |

**关于 `message` 的写法**：

```python
# ❌ 差：AI 不知道发生了什么
return {"status": "success", "message": "ok"}

# ✅ 好：AI 能直接用这个信息回答用户
return {"status": "success", "message": "北京当前 24℃，晴，湿度 45%"}
```

**长度限制**：`message` 会被截断到 8000 字符（可在插件配置里调 `max_output_chars`）。
**不要把大段原始 JSON 塞进 message** —— 既浪费 AI 的上下文，又不好读。

### 3.4 参数类型对照表

| docstring 类型 | 注解写法 | AI 会传 | 示例 |
|----------------|----------|---------|------|
| `string` | `str` | 字符串 | `"北京"` |
| `integer` | `int` | 整数 | `3` |
| `number` | `float` | 小数 | `1.5` |
| `boolean` | `bool` | 真/假 | `true` |
| `array` | `list` | 数组 | `["a", "b"]` |
| `object` | `dict` | 对象 | `{"k": "v"}` |

**优先级**：docstring 里的类型 > 类型注解。两者都写时以 docstring 为准。

**注意**：AI 传参可能不精确（比如该传整数却传了 `"3"`）。**建议在函数开头自己转换**：

```python
def main(days) -> dict:
    """..."""
    try:
        days = int(days)
    except (TypeError, ValueError):
        days = 1
    ...
```

## 4. 运行环境

你的代码运行在一个**隔离子进程**里，与 AstrBot 主进程隔离。

### 4.1 可以用的库

**标准库**（常用的一部分）：

```
json      re        math       datetime   random     time
urllib.request（仅公网）       base64     hashlib    itertools
collections          textwrap   string     decimal    fractions
statistics           uuid       zlib       gzip       csv
```

**第三方库**（AstrBot 环境里已有）：

```
aiohttp    Pillow (PIL)    psutil
```

> 需要其他库？可以在服务器上 `docker exec astrbot pip install <包名>` 安装，
> 但**插件更新后可能丢失**，建议优先用标准库。

### 4.2 文件操作

- 当前工作目录 = 插件工作区（`data/plugin_data/astrbot_plugin_qzone_tools/workspace/`）
- **写文件请用相对路径**：`open("result.txt", "w")`  ✅
- 绝对路径会被静态检测拦截（见 §5）

### 4.3 `wyc` 辅助对象

代码里可以直接用 `wyc`：

```python
def main() -> dict:
    """..."""
    wyc.log("调试信息")            # 写日志（在服务器日志里能看到）
    p = wyc.workspace              # 工作区绝对路径字符串
    return {"status": "success", "message": p}
```

| 成员 | 说明 |
|------|------|
| `wyc.log(*args)` | 写日志到 stderr（不会污染返回结果） |
| `wyc.workspace` | 工作区路径字符串 |
| `wyc.image(path)` | 声明「这张图要发给 AI」，等价于返回 `screenshot` 字段 |

**返回图片的两种方式**：

```python
# 方式一：直接给路径
return {"status": "success", "message": "已生成图表", "screenshot": "chart.png"}

# 方式二：用 wyc.image（适合生成多张图时选一张）
wyc.image("chart.png")
return {"status": "success", "message": "已生成图表"}
```

> ⚠️ `screenshot` **只接受文件路径**，不接受 base64 或 `data:` 开头的字符串。
> 图片必须真实存在于工作区。

## 5. 禁止事项（硬约束）

代码在保存时会做**静态检测**，违反以下任何一条都会**拒绝保存**。

### 5.1 禁止导入的模块

```
subprocess    os        sys         shutil      ctypes
multiprocessing         socket      http        ftplib
smtplib       pty       signal      resource    importlib
pickle        marshal   builtins    gc
```

> **为什么禁 `os`**：它能读写任意文件、执行命令。
> 需要路径拼接？用字符串操作或 `pathlib`（`from pathlib import Path`）。
> 需要环境变量？不需要 —— 沙箱已提供 `wyc.workspace`。

### 5.2 禁止调用的函数

```
eval    exec    compile    __import__
getattr(x, "system")      这类动态取值
```

### 5.3 禁止的路径

```
/etc  /proc  /root  /www  /AstrBot  下的绝对路径
```

### 5.4 资源限制

| 限制 | 值 |
|------|-----|
| 执行超时 | 默认 30 秒（可配置，上限 120 秒） |
| 内存 | 2 GB |
| 单文件写入 | 100 MB |
| 子进程数 | 64 |
| 输出长度 | 8000 字符 |

超时会**强制杀死进程**，返回「执行超时」。

### 5.5 网络访问

`urllib.request` 和 `aiohttp` 可以用，但**只建议访问公网地址**。
访问内网地址（`127.0.0.1`、`10.x`、`192.168.x`、云元数据地址）在插件其他工具里是被拦截的。

> ⚠️ 注意：子进程内的网络请求**不经过插件的 SSRF 校验**（那是给 `fetch_url` 等内置工具用的）。
> 也就是说，你写的代码能访问什么，取决于服务器本身的网络环境。**请自行确保请求的目标是你信任的**。

## 7. 完整示例

### 7.1 调用公开 API（带异常处理）

```python
import json
import urllib.request

def main(city: str) -> dict:
    """查询指定城市的实时天气。

    Args:
        city(string): 城市名，如「北京」
    """
    try:
        url = f"https://wttr.in/{city}?format=j1"
        with urllib.request.urlopen(url, timeout=8) as r:
            data = json.loads(r.read().decode("utf-8"))
        cur = data["current_condition"][0]
        desc = cur["lang_zh"][0]["value"]
        return {
            "status": "success",
            "message": f"{city} {cur['temp_C']}℃，{desc}，湿度 {cur['humidity']}%",
        }
    except Exception as e:
        return {"status": "error", "message": f"查询失败：{type(e).__name__}: {e}"}
```

### 7.2 计算类（注意类型容错）

```python
import math

def main(expr: str) -> dict:
    """计算一个数学表达式。支持 + - * / ** 与常用数学函数。

    Args:
        expr(string): 数学表达式，如 2*3+4 或 sqrt(16)
    """
    allowed = {k: getattr(math, k) for k in dir(math) if not k.startswith("_")}
    allowed.update({"abs": abs, "round": round, "min": min, "max": max})
    try:
        result = eval(expr, {"__builtins__": {}}, allowed)
    except Exception as e:
        return {"status": "error", "message": f"表达式无法计算：{e}"}
    return {"status": "success", "message": f"{expr} = {result}"}
```

> ⚠️ 这里用了 `eval`，**会被静态检测拦截**。
> 上面的写法只是展示「受限 eval」的思路，实际保存时请改用
> 自己写解析器，或改用 `ast.literal_eval`（仅支持字面量）。

### 7.3 处理工作区文件

```python
import json

def main(filename: str) -> dict:
    """读取工作区里的 JSON 文件并统计条数。

    Args:
        filename(string): 工作区内的文件名，如 data.json
    """
    try:
        with open(filename, encoding="utf-8") as f:
            data = json.load(f)
    except FileNotFoundError:
        return {"status": "error", "message": f"工作区里没有文件 {filename}"}
    except json.JSONDecodeError as e:
        return {"status": "error", "message": f"{filename} 不是合法 JSON：{e}"}
    n = len(data) if isinstance(data, (list, dict)) else 1
    return {"status": "success", "message": f"{filename} 含 {n} 条数据"}
```

### 7.4 画图并返回给 AI

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

def main(title: str = "示例图表") -> dict:
    """生成一张柱状图并返回给 AI 查看。

    Args:
        title(string): 图表标题
    """
    fig, ax = plt.subplots(figsize=(6, 4))
    ax.bar(["一月", "二月", "三月"], [12, 19, 7])
    ax.set_title(title)
    fig.tight_layout()
    fig.savefig("chart.png", dpi=100)
    plt.close(fig)
    return {"status": "success", "message": "已生成图表", "screenshot": "chart.png"}
```

> 中文字体已自动配置，直接写中文即可。
> `screenshot` 只接受**工作区内的相对路径**。

### 7.5 文本处理

```python
import re

def main(text: str, pattern: str = r"\d+") -> dict:
    """用正则从文本里提取所有匹配项。

    Args:
        text(string): 要处理的文本
        pattern(string): 正则表达式，默认提取数字
    """
    try:
        found = re.findall(pattern, text)
    except re.error as e:
        return {"status": "error", "message": f"正则写法有误：{e}"}
    if not found:
        return {"status": "success", "message": "没有匹配到内容"}
    return {"status": "success", "message": f"找到 {len(found)} 项：{', '.join(map(str, found[:20]))}"}
```

## 8. 调试技巧

### 8.1 用「试跑」验证

编辑抽屉底部的「试运行」可以**直接跑还没保存的代码**：

1. 在「参数（JSON）」里填测试参数，如 `{"city": "北京"}`
2. 点「运行」
3. 看结果：绿色是成功，红色是失败（会显示完整错误信息）

**这是最快的调试方式** —— 不用保存、不用去 QQ 里问 AI。

### 8.2 用 `wyc.log` 打日志

```python
def main(x: str) -> dict:
    """..."""
    wyc.log("收到的参数:", repr(x))
    result = do_something(x)
    wyc.log("中间结果:", repr(result))
    return {"status": "success", "message": str(result)}
```

日志会出现在「试运行」的结果里（标为 `[stderr]`），也会进服务器日志：

```bash
docker logs --since 5m astrbot 2>&1 | grep -i custom
```

### 8.3 注意「参数预览」

编辑代码时，下方会实时显示解析出的参数表：

```
city   string   必填   城市名，如「北京」
```

- **如果参数没出现** → docstring 的 `Args:` 段格式写错了
- **如果类型不对** → 检查 `参数名(类型)` 里的类型词
- **如果显示「未写说明」** → 该参数在 `Args:` 里没写描述

### 8.4 常见错误对照表

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `禁止导入模块: os` | 代码里有 `import os` | 改用 `pathlib`，或用 `wyc.workspace` |
| `禁止调用: eval` | 用了 `eval`/`exec`/`compile` | 换实现方式 |
| `找不到入口函数 main()` | 函数名不是 `main`，或不是顶层函数 | 确认 `def main(...)` 在文件顶层 |
| `缺少必填参数：city` | AI 没传参 / 试运行时 JSON 里没写 | 检查参数名拼写 |
| `执行超时` | 代码跑太久（网络卡住/死循环） | 给网络请求加 `timeout=`，检查循环 |
| `代码包含禁止的内容` | 触发静态检测 | 看提示里指出的具体规则 |
| `语法错误（第 N 行）` | Python 语法问题 | 按行号检查（常见：中英文标点混用） |
| `执行器未返回有效结果` | 代码崩溃且没被 try 捕获 | 加 try/except，用 `wyc.log` 定位 |

### 8.5 写中文代码的注意点

最常见的原因是**中英文标点混用**：

```python
# ❌ 中文冒号、中文括号、中文引号
if x（1）：
    return ｛"status"： "success"｝

# ✅ 全部英文标点
if x(1):
    return {"status": "success"}
```

字符串里的中文没问题，**只有代码结构部分必须用英文标点**。

## 9. 让 AI 更容易调用你的工具

工具写得对，不等于 AI 会用。以下几点决定 AI 能否**找对、用对**：

### 9.1 描述要写「什么时候用」

AI 靠 `描述` 决定要不要调用这个工具。

```python
# ❌ 差：AI 不知道什么时候该用它
def main(city):
    """天气工具。

    Args:
        city(string): 城市
    """

# ✅ 好：明确触发场景 + 参数格式
def main(city):
    """查询指定城市的实时天气、温度与湿度。
    当用户询问某地天气、气温、是否下雨、湿度时调用。

    Args:
        city(string): 城市名，中文即可，如「北京」「上海」
    """
```

### 9.2 搜索词要覆盖「用户会怎么问」

「搜索词」是 AI 搜索工具时的匹配依据。填**口语说法**，不是技术词：

```
查天气的工具：
❌ weather api query
✅ 天气, 气温, 温度, 下雨, 冷不冷, 热不热, 天气预报, weather
```

### 9.3 参数越少越好

```python
# ❌ 三个参数，AI 容易漏传或传错
 def main(city: str, unit: str, lang: str) -> dict: ...

# ✅ 只留必要的，其余给默认值
 def main(city: str) -> dict: ...
```

### 9.4 参数名要直白

```python
# ❌ AI 可能不知道要传什么
 def main(q: str) -> dict: ...

# ✅ 一看就懂
 def main(city: str) -> dict: ...
```

## 10. 常见问题

**Q：保存时报「功能未启用」？**
A：先到左侧导航的「**配置**」页，开启「**启用自定义 Python 函数工具**」，点「保存配置」，再回来。

**Q：AI 搜不到我写的工具？**
A：三个原因，按顺序排查：
1. 工具是否**启用**（列表里应显示「已注册」）
2. 权限档位 —— 默认是「**超管**」，只有 AstrBot 全局管理员能用
3. 搜索词不够 —— 在「补充工具搜索词」页给它多加几个口语说法

**Q：为什么只有管理员能用？**
A：自定义工具可以执行任意 Python 代码，风险等同于 `run_python_code`。
默认「超管」且**不可降档**是安全设计。
如果确实要给所有人用，需先在配置里开启「允许把自定义工具设为『全局』档」。

**Q：能在工具里调用其他插件工具吗（比如发消息）？**
A：当前版本**不支持**。自定义工具运行在隔离子进程里，无法访问插件的其他能力。
需要组合操作时，让 AI 依次调用多个工具即可。

**Q：代码存在哪里？**
A：`data/plugin_data/astrbot_plugin_qzone_tools/custom_tools.json`。
**注意**：这是明文存储，不要在里面写密钥、密码。

**Q：插件更新后工具会丢吗？**
A：不会。自定义工具存在 `data/` 目录（持久化数据），插件更新/重装都不会覆盖。

**Q：怎么备份/迁移？**
A：直接复制 `custom_tools.json` 即可。

**Q：最多能建多少个工具？**
A：50 个。单个工具代码上限 256 KB。

**Q：能装额外的 Python 库吗？**
A：可以 `docker exec astrbot pip install <包名>`，但**插件更新后可能丢失**。
建议优先用[§4.1 列出的库](#41-可以用的库)。

**Q：超时时间能改吗？**
A：能。单个工具可在编辑抽屉里设（5-120 秒），全局上限在「配置」页的
「自定义工具」卡片里调（`custom_tools_timeout_max`）。
**注意**：实际生效值还会被 AstrBot 全局「工具调用超时时间」钳制（自动预留 12 秒收尾）。

**Q：为什么我的网络请求在内网地址上没被拦？**
A：插件的 SSRF 防护作用于**内置工具**（`fetch_url` 等）。
自定义工具在子进程里运行，网络请求不经过那层校验。
所以请自行确认请求目标是可信的。
